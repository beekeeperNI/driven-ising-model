# Figures from the final Research Note

These PNGs are the actual embedded images extracted losslessly from [the final PDF](../../paper/research_note.pdf). No curves were redrawn, no values were digitized, and no older exploratory figures were substituted. Their native resolution is preserved; upscaling would not recover additional information.

| File | Paper figure | PDF page (counting the cover) | Native pixels |
|---|---|---:|---:|
| [Period response](period_hysteresis.png) | 6 | 20 | 769 × 546 |
| [Temperature response](temperature_hysteresis.png) | 12 | 27 | 778 × 546 |
| [Finite-size response](finite_size_work_order.png) | F1 | 30 | 1290 × 495 |

The first two figures show the absolute trapezoidal hysteresis integral. Figure F1 shows signed field work and mean absolute dynamic order. These definitions are intentionally kept distinct.

[provenance.json](provenance.json) records the PDF Git blob, SHA-256 digest, image object names, dimensions, and extracted-file hashes. The PDF itself is unchanged.
