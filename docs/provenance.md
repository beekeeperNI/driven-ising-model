# Project provenance and reuse

The project began as a collaborative UC Berkeley Physics 77 capstone. Group A investigated periodic magnetic driving using a shared Ising-model Metropolis baseline. Fengrui Yang subsequently extended the investigation into temperature, initial states, finite-size effects, and numerical reliability. This repository does not claim sole authorship of the shared baseline.

AI assistance was used for coding, troubleshooting, visualization, repository organization, and editing. The research note and retained results define the scientific claims; repository restructuring is not an additional validation of every parameter regime.

No software license has been selected. Ownership and reuse rights for the collaborative starting code should be reviewed before choosing a license. No license is introduced by this portfolio update.

The authoritative research records are the unchanged [final PDF](../paper/research_note.pdf) and [25-cell notebook](../notebooks/Simulator.ipynb). The existing GIF gallery is preserved as earlier supplementary demonstrations. Historical experiment data are retained with their original provenance.
